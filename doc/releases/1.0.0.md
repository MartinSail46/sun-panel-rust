# Sun-Panel Rust 1.0.0

首个 Rust 单用户正式版本。面向个人服务器、NAS 和浏览器首页，一个进程提供网页、API 与上传图片，使用 SQLite 保存数据，无需外部数据库或 Redis。

## 主要功能

- **Rust 后端**：以 Axum、Tokio、SQLx 与 SQLite WAL 替换 Go 服务，统一静态文件、上传图片、健康检查和数据维护入口。
- **单用户导航**：免登录访问同一工作区，每项只有一个地址；保留分组、应用搜索、网页搜索及当前页、新标签、小窗口打开方式。
- **直接拖动**：编辑模式下应用可拖到同组、其他分组和空分组，松手自动保存；监控卡片在监控区域独立排序。
- **回收与撤销**：应用与分组删除后持久化保存在回收站；支持恢复、指定目标分组恢复和永久删除。当前页面保留最近 20 步导航撤销。
- **界面与外观**：Vue 3、shadcn-vue / Reka UI 与 Tailwind CSS 4；保留文字、图片与 Iconify 图标，支持独立卡片风格、壁纸、布局、中文界面、明暗主题和自定义页脚。
- **系统监控**：CPU、内存、磁盘共享采样缓存，页面后台暂停轮询，读取失败或过期时保留状态提示。
- **数据维护**：新版导航 JSON 支持导入预览、合并、追加、替换及冲突检查；离线 CLI 支持数据库一致快照、图片和 SHA256 清单的完整备份恢复。

## 保存与部署改进

- 导航移动与排序在事务中校验版本，避免旧页面覆盖新排列；配置保存支持字段冲突处理。
- 写请求中断后先核对结果，避免自动重放产生重复操作；编辑器和上传支持取消。
- 图片管理显示用途与引用数量，阻止删除仍被导航、壁纸或页脚使用的本地图片。
- Docker 使用多阶段构建、非 root 运行、内置健康检查与持久化数据卷；静态文件构建时生成 Brotli / Gzip 资源。
- 清理旧 Go 源码、账号 / 公告 / 验证码兼容入口、演示页面、重复配置，以及原项目捐赠、群二维码和宣传截图。保留 MIT 版权与来源说明。

## 启动

在本版本源码目录执行：

```sh
docker compose up --build -d
```

访问 `http://127.0.0.1:3002`。默认端口只向本机开放，数据保存在 Compose 命名卷中；`docker compose down` 保留数据，`docker compose down -v` 会删除数据卷。

本地构建镜像：

```sh
docker build -t sun-panel-rust:1.0.0 .
```

镜像名用于本地构建；公共镜像地址以本仓库实际发布配置和工作流结果为准。多架构工作流配置不代表每个架构已在本机验证。

## 升级与兼容

- **升级前停止服务并完整备份。** 已有 Rust 实例保留原数据卷，SQL 迁移在启动时执行；不要删除或改写历史迁移文件。需要回退时使用旧镜像和对应旧备份。
- **旧 Go 数据库和旧版 `.sun-panel.json` 不能直接导入。** 本版只接受 `Sun-Panel-Navigation`、`schemaVersion: 1` 导航文档与 Rust 完整实例备份。
- 导航 JSON 只包含分组、应用及图标引用，不包含图片实体、外观和小组件；整个实例的迁移应使用离线 `backup` / `restore`。
- 账号、密码、公开访问模式与内外网双地址已移除。本版没有用户权限隔离；可信网络之外的访问需在网关或反向代理中配置认证。
- 监控反映服务运行环境，容器中的读数不保证等同于完整宿主 NAS 或容器配额。网页小窗口是否显示取决于目标网站的嵌入策略。

部署、备份恢复、验证命令与上游功能对比均随本版本源码中的 `README.md` 和 `service-rust/README.md` 提供。
